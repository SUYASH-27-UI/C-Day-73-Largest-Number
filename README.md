# C Day 73 - Find the Largest Number

This C program accepts multiple numbers from the user and finds the largest number using a `for` loop and an `if` statement.

## Example

Input numbers:
```text
12, 45, 23, 67, 30
```

Output:
```text
Largest number = 67
```

## Concepts Used

- `for` loop
- `if` statement
- Comparison operator `>`
- Variables
- `scanf()` and `printf()`

## How It Works

The program takes numbers one by one. The first number is stored as the initial largest number. Each following number is compared with it. If a larger number is found, the `largest` variable is updated.
